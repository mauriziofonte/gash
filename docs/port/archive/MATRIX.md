# MATRIX

Every public surface item of Gash 2.1.0 with its 3.x decision (PRD 8), then the new 3.x surface (PRD 10,
item 18). The operator approved both at S1 on 2026-10-18 (decisions D-6 and D-8 in `go-impl/design/README.md`);
a later change to a row needs a LEDGER item or the operator's word.

* **kind**: `function`, `compat function` (a helper external harnesses may call after sourcing one of the 7
  shim paths), `alias`, `flag` (synonyms together, as `name -n/--limit`), `env var`, `setting` (a
  `~/.gash_env` entry), `file`, `path`.
* **class**: `pure output`, `shell-mutating` (changes the calling shell or the disk where the user expects
  it), `interactive` (prompts or needs a terminal); `-` where it does not apply.
* **decision**: `port` (same contract in Go, defects included: the LEDGER id is named), `redesign` (same
  name and purpose, implementation or behavior changes for the stated reason), `drop` (not in 3.x).
  A port that is a forced divergence names its LEDGER item.
* **Go command**: what runs the item in 3.x; for aliases, the shell definition the generated Bash keeps.
* **Tests**: the 2.x specs that cover the item, or the Go test to add.
